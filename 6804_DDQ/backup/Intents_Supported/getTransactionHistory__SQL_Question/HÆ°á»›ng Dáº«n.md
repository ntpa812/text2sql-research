# Kết nối DB:

Công cụ: https://dbeaver.io/download/

Tải về, rồi kết nối với DB qua thông tin sau:

```
Mariadb
url: jdbc:mariadb://192.168.3.7:3306
username: bank-gateway
password: bankgateway@123
```

## Nhiệm vụ:

Vào DB, lấy thông tin cần thiết (VD: account_number) và ghép vào SQL để chạy thử.

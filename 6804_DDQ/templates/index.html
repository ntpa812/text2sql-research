Upload Documents từ Excel

Tải file Excel mẫu (dữ liệu từ API getAccountDetail)

Cấu trúc file Excel:
- document (bắt buộc): Tên API/Chức năng. VD: "API getAccountDetail"
- description: Mô tả chi tiết chức năng của API
- examples: Các câu hỏi mẫu người dùng có thể hỏi
- keyword: Từ khóa liên quan (tiếng Việt + tiếng Anh)
- metadata: Thông tin JSON (api_code, function, category...)
